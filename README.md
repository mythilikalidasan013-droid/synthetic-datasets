# synthetic-datasets
"Data cleaning practice project using synthetic datasets – handling missing values, mean/median imputation, and encoding."

Beginner Data Cleaning & Preprocessing Project 🧹📊
This project demonstrates fundamental data cleaning techniques on a synthetic dataset using Python (Pandas & NumPy). The workflow covers:

Handling missing values with dropna() and fillna()

Using mean and median for imputation

Applying encoding techniques for categorical features

Exploring dataset structure with .info(), .describe(), and value counts

👉 Purpose: Practice and showcase data preprocessing skills as part of my learning journey in Data Analytics & AI.
